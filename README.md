# 🐾 내 안에 사는 고양이 MBTI 테스트

16개의 질문으로 나의 성향을 고양이 캐릭터로 만나보는 웹 테스트입니다.
수채색연필 느낌의 고양이 일러스트와 따뜻한 종이 색감으로, 나를 알아가는 작고 다정한 시간을 담았습니다.

👉 **[테스트 바로가기](https://cdev2024.github.io/mbti/)**

## 주요 기능

- **16문항 · 약 2~3분**: 고양이의 일상 속 상황에서 나와 가까운 답을 선택합니다.
- **16가지 고양이 결과**: MBTI 유형, 고양이 품종, 성격, 집사와의 관계, 좋아하는 것과 싫어하는 것을 확인합니다.
- **성향 비율 표시**: E/I, S/N, T/F, J/P 네 가지 축의 비율을 보여줍니다.
- **닉네임 설정**: 기본값은 **냐옹**이며, 최대 12자까지 변경할 수 있습니다.
- **고양이 카드 저장**: 닉네임과 결과가 담긴 **1080 × 1350 PNG**를 내려받습니다.
- **친구에게 공유**: 지원하는 브라우저에서는 공유 메뉴를 열고, 그 외에는 공유 문구와 링크를 복사합니다.
- **최근 결과 다시 보기**: 같은 브라우저에 저장된 최근 결과를 다시 확인할 수 있습니다.
- **고양이 도감**: 시작 화면과 결과 화면에서 16가지 고양이를 모아 볼 수 있습니다.
- **반응형 화면**: 모바일과 데스크톱 화면에 맞춰 배치가 바뀝니다.

## 디자인

첫 화면에는 다섯 마리 고양이가 함께 등장합니다. 결과별 고양이 16종도 수채색연필 드로잉 스타일로 구성했습니다.

크림색 배경, 차분한 초록과 로즈색 포인트, 둥근 카드와 버튼을 사용합니다. 이미지 17장은 모두 Base64 데이터 URI로 HTML 안에 포함되어 있어 별도 이미지 파일을 준비할 필요가 없습니다.

## 실행 방법

1. `index.html`을 내려받습니다.
2. 웹 브라우저에서 파일을 엽니다.
3. 닉네임을 입력하고 테스트를 시작합니다.

설치나 빌드 과정이 없습니다. 테스트 진행과 결과 확인은 인터넷 연결 없이도 사용할 수 있습니다. 링크를 통해 다른 사람이 접속하려면 웹에 배포해야 합니다.

## GitHub Pages에 올리기

저장소의 배포 대상 폴더에 아래 두 파일을 넣습니다.

- `index.html` — 앱 전체 코드와 내장 이미지
- `README.md` — 프로젝트 소개와 사용 안내

GitHub Pages가 해당 폴더를 제공하도록 설정하면 `index.html`이 첫 화면으로 열립니다. HTML 파일명은 소문자 **index.html**로 유지하세요.

현재 코드의 공유 주소는 아래와 같습니다.

```js
const SHARE_URL = 'https://cdev2024.github.io/mbti/';
```

다른 주소로 배포하면 `index.html` 안의 `SHARE_URL`도 새 주소로 변경하세요. 파일을 교체한 뒤 배포가 완료되면 새 디자인이 서비스에 반영됩니다.

외부 라이브러리나 서버 API 없이 단일 HTML 파일로 동작합니다. 공유 방식과 이미지 파일 공유 지원 여부는 브라우저 및 기기에 따라 달라집니다.

## 결과 계산

네 가지 성향 축마다 4문항씩, 총 16문항으로 구성됩니다.

각 문항의 네 선택지에는 순서대로 `+2, +1, -1, -2` 점수가 부여됩니다. 축별 합계가 양수이면 E·S·T·J, 음수이면 I·N·F·P를 선택합니다. 합계가 0이면 해당 축의 마지막 문항 응답으로 유형을 결정합니다.

첫 번째 성향의 비율은 `round((합계 + 8) / 16 × 100)`으로 계산하며, 반대 성향은 나머지 비율로 표시합니다.

이 테스트는 고양이 캐릭터를 통해 성향을 즐겁게 살펴보는 콘텐츠이며, 공식 MBTI 검사나 심리 진단 도구는 아닙니다.

## 데이터 보관

닉네임, 응답, 최근 결과는 브라우저의 `localStorage`에 저장합니다. 앱 코드에는 이를 서버로 전송하는 기능이 없습니다.

브라우저나 기기를 바꾸면 저장된 결과가 이어지지 않으며, 브라우저의 사이트 데이터를 삭제하면 최근 결과도 삭제됩니다.

## 수정할 때

`index.html` 안에서 아래 항목을 수정할 수 있습니다.

- `<style>`: 색상, 여백, 글꼴, 반응형 배치
- `QUESTIONS`: 질문, 선택지, 성향 축과 점수
- `RESULTS`: 유형별 품종, 설명과 결과 이미지
- `HERO_IMAGE`: 첫 화면의 고양이 단체 이미지
- `DEFAULT_NICKNAME`: 기본 닉네임
- `SHARE_URL`: 공유할 테스트 주소

이미지를 교체할 때는 `data:image/jpeg;base64,...` 형태의 데이터 URI를 사용하면 단일 파일 구성을 유지할 수 있습니다.
